KLG Print Agent · Windows

安装步骤

  1. 在办公室能正常打印的 Windows 电脑操作。先确认 Windows 可以打印到 DocuCentre-V C2265。
  2. 打开系统 Billing → Office printer，按 Create connection code。
  3. 下载 Install-KLG-Print-Agent.cmd，双击运行。若公司电脑阻止脚本，请交给办公室 IT 审核安装；不要关闭电脑安全保护。
  4. 输入打印机的编号，再粘贴连接码。输入连接码时屏幕不显示文字。缺少 SumatraPDF 时，安装程序会通过 Windows Package Manager 安装免费版 3.6.1；没有该工具时会打开官方安装页面。
  5. 回到系统按 Print one test page，约 60 秒内处理。确认只印出一张 A4 测试纸。
  6. 到 Schedule & holidays 确认租金开始月份、时间、公共假期及补假，并填写 Calendar checked through。此系统不会自动判断未列入的假期。
  7. 回到 Office printer，勾选已核对测试纸，选第一个自动账单月份，再按 Enable rental auto-print。Utilities 不会自动打印。

运行和补印

电脑必须开机、联网，并登录安装时的 Windows 账号；锁屏可继续运行，关机、睡眠或登出无法处理。登录后会自动启动，每 60 秒检查一次。错过的租金月份会在下一个符合日历及时间的日期补处理。

Submitted 仅表示已交给 Windows，缺纸、卡纸或打印机离线需到打印机处理。Claimed 表示处理可能被中断，系统不会自动重印。核对 Windows 队列和纸张后才按 Review / retry，并填写原因。

已印出的租金单不会因重新连接而自动再印。更换照片或 reading 不影响已排入队列的租金快照。

暂停、断开和记录

系统 Office printer 页面可按 Pause automatic rentals 暂停，或 Disconnect office PC 撤销连接码。旧连接码随即无法取新单。已经交给 Windows 的任务需在 Windows 打印队列取消。

桌面 KLG Print Agent - Status 打开系统状态页。本机文件在 %LOCALAPPDATA%\KLGPrintAgent：连接码使用 Windows 用户加密，invoice PDF 和送印记录保留于 jobs；agent.log 记录运行情况。

取消自动启动：按 Win+R，输入 shell:startup，删除 KLG Print Agent 快捷方式。保留 jobs 文件夹，避免丢失送印审计记录。

验证范围

服务器日期、权限、防重复及旧回执防护已做自动测试。Windows 驱动、电脑权限、浏览器 PDF 渲染与真实出纸需在办公室测试。安装程序不是购买的服务，SumatraPDF 为免费软件。
